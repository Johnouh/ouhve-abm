보호자 등록 서비스
회원(예: 자녀)에게 보호자를 등록하면 회원 출석 시 보호자는 알림을 받을 수 있어요.
보호자 등록 경로  
•
CRM → 회원 → 회원 상세 → 보호자 등록 버튼
•
강사앱 → 회원 관리 → 회원 상세 → 보호자 등록 버튼

연결된 회원/보호자 리스트 조회 경로
•
회원앱 → MY → 연결된 회원/보호자
•
보호자 등록 후 보호자에게 회원 연결 승인 요청을 보내요.
•
보호자가 회원앱에서 승인하면, 보호자–회원 연결이 완료돼요.
•
연결이 완료된 회원이 센터에 출석하면, 보호자에게 출석 알림(푸시 알림)이 전송돼요.
•
알림 수신 조건은 다음과 같아요.
◦
보호자가 회원앱 가입 및 시설 등록을 완료해야 해요.
◦
회원앱에 가입한 정보가 보호자 등록 시 입력한 정보와 일치해야 알림을 받을 수 있어요.
◦
보호자가 승인 요청을 거절할 시에는 연결되지 않으며 알림이 발송되지 않아요.
◦
알림 내용을 다음과 같아요.
김회원님 출석 완료
어시스트핏 강남점에 김회원님이 출석했어요.
