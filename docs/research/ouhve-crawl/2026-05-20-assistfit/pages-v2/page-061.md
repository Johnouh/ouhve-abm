그룹 수업 휴강하기
경로
· 그룹 수업 → 수업 목록 → 휴강 버튼 클릭
휴강
•
휴강 처리는 관리자, 강사 모두 가능해요.
•
하루 또는 기간을 선택하여 과거/현재/미래 날짜로 자유롭게 휴강 등록이 가능해요.
•
휴강 등록 시 회원 예약 차단 및 기존 예약 자동 취소 + 회원에게 푸시가 발송돼요.
•
휴강 등록 시 메모 작성이 가능하고 회원에게는 노출되지 않아요.
휴강 취소
•
휴강 처리 후 수정이 불가하고, 취소만 가능해요.
•
휴강 예정, 휴강 중, 지난 휴강인 상태에서도 취소가 가능해요. 단, 휴강 취소 시 기존 회원의 예약을 다시 복구되지 않아요.
•
휴강 취소 즉시 수업 진행 기간 동안 수업이 재개돼요.
스케줄 휴강 표시
•
휴강 처리 시 스케줄에 휴강 표시가 돼요.
