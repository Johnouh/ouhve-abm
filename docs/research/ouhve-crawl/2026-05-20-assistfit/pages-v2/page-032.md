시작하기
어시스트핏 강사앱을 사용하기 전, 필요한 과정을 확인해 보세요.
프랜차이즈 선택
•
프랜차이즈 선택에서 관리 / 사용할 시설을 선택해 주세요.
•
시설의 권한이 필요하다면, ‘접속 권한 요청’ 버튼을 클릭 해 검색 후, 시설을 추가해 주세요.
접속 권한 요청
관리할 센터를 추가하고 싶으시다면, 프랜차이즈 선택 페이지에서 ‘접속 권한 요청’을 눌러주세요.
권한 추가를 요청하면 시설 관리자가 확인 후, 승인해야 앱을 사용하실 수 있어요.
프랜차이즈 선택
연결할 프랜차이즈 또는 센터명을 입력해 주세요.
별도의 지점이 없는 경우, 프랜차이즈에 시설 이름을 입력해 주세요.
카테고리 선택
센터에서 운영하는 카테고리를 선택해 주세요.
지점명 선택
프랜차이즈에 다양한 지점이 있을 경우, 권한을 요청할 지점을 선택해 주세요.
본인 인증
센터에서 강사 계정을 만들었다면, 본인 인증이 필요해요.
본인 인증을 진행한 후 강사앱을 이용해 주세요.
센터 권한 설정
여러 센터를 담당하고 있다면, 센터 설정을 확인해 보세요.
앱에서 바로바로 센터를 전환할 수 있어요.
다양한 시설을 담당하고 있다면 한 번 써 보세요.
