그룹 수업 예약 마감 시간 설정
•
회원이 수업 시간 직전까지 예약을 했을 경우를 대비해 예약 마감 시간을 직접 설정할 수 있어요.
•
예를 들어 19시 수업의 예약 마감 시간이 ‘수업 시작 1시간 전’으로 설정되어 있다면, 회원은 18시 01분부터는 해당 수업을 예약할 수 없어요.
•
그래서 회원앱에는 예약 마감 배지가 노출될 거에요.
