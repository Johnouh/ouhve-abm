‘그룹 수업’ 상품 유형 추가
기존에는 회원권에 포함되어 있던 그룹 수업이 별도 상품 유형으로 분리되었어요. 
경로
상품 → 상품 추가
상품 → 그룹 수업 탭
회원 → 회원 목록 → 회원 상세 → 그룹 수업 탭
•
그룹 수업도 이용권 종류를 설정할 수 있어요. 
◦
기존 상품은 ‘기타’로 분류돼요. 상품 상세 페이지에서 이용권 종류를 수정할 수 있어요. 
•
이미 생성된 상품이나 회원이 보유한 상품은 그룹 수업 탭에서 모아볼 수 있어요. 
•
직원별 매출, 출석, 스케줄, 통계도 그룹 수업 항목만 따로 확인할 수 있어요.
