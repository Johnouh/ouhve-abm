# AssistFit UI/UX 분석

> 대상: 95장 스크린샷 중 대표 22장 시각 분석
> 목적: OUHVE ABM 디자인 보강 (Persimmon + Slate + Teal 시스템 유지)

## 디자인 시스템 추정

| 토큰 | HEX 추정 | 용도 |
|---|---|---|
| Primary Orange | `#FF6B3D ~ #FF7849` (Persimmon 톤) | 메인 CTA, 로고, 활성 탭, KPI 강조 |
| Light Orange tint | `#FFE4D6 ~ #FFF1E8` | 카드 배경, 빈 상태, 아바타 |
| 시맨틱 빨강 | `#FF3B30` (▲) | 결제 취소/환불 도입 |

**OUHVE 친화**: AssistFit Primary가 OUHVE Persimmon `#FF5A1F`와 같은 따뜻한 오렌지 계열 → 패턴 흡수 시 Persimmon으로 그대로 치환 가능.

### 카테고리 컬러 시스템 (가이드 챕터 카드)
- 회원=Orange / 직원=Brown / 상품=Coral / 스케줄=Blue / 통계=Indigo / 개인레슨=Burnt Orange / 메시지=Pink / 락커=Forest Green
- → OUHVE 규칙 충돌. **Slate 톤 변주**로만 흡수.

### 타이포 / 모서리
- Pretendard 산세리프, 헤딩 28-32px Bold
- 모바일 카드 `rounded-2xl` (16-20px), 가이드 표지 `rounded-3xl`(24px)
- 풀폭 하단 고정 CTA = 모바일 표준

## 레이아웃

| 화면 | 패턴 |
|---|---|
| 가이드 사이트 | 1컬럼 720-960px, breadcrumb + Search/Share/다크모드 토글 |
| CRM PC | 좌 사이드바 + 메인 카드 그리드 + 데이터 테이블 |
| 모바일 앱 | 헤더(뒤로/타이틀/액션) + 풀폭 하단 Primary CTA + 4-5 탭바 |
| 키오스크 | 검은 외장 + 흰 화면 + Orange CTA 큰 글씨 |

## 컴포넌트 패턴

- **챕터 표지 카드**: 풀컬러 + 검정 chip + 흰 헤딩 + 우측 일러스트
- **회원 카드 (강사앱)**: 아바타(Orange tint 원) + 이름/등급 / 잔여횟수·만료일 bold
- **결제/주문 카드**: chip → 큰 수치 → 보조 → 하단 CTA (위계 명확)
- **리스트**: 1줄 1회원, 아바타+이름+보조+우측 chevron, 상태=컬러 dot
- **테이블**: PC=얇은 행+우측 액션, 모바일=카드 변환
- **탭/필터**: 주간/월간 segmented + "오늘" 단축 버튼
- **배지/Chip**: `rounded-full` Pastel 라벨, 카테고리는 검정+흰
- **빈 상태**: 큰 일러스트 (SaaS 양산 UI 탈피)

## 데이터 시각화 (page-033 통계 조회)
- 상단 빅 KPI: "이번 달 매출 / 1,500,000원"
- 항목별 매출: 좌 컬러 아이콘 + 중앙 라벨 + 우측 금액 (tabular-nums)
- 도넛(성별) + 막대(회원 통계)
- 차트 컬러 3색 단순화: Orange + Blue + Gray

## 화면별 인사이트 (대표)

- **page-001 인덱스**: 챕터별 풀컬러 카드 그리드 → OUHVE 도움말/온보딩 패턴
- **page-033 통계 조회 (모바일)**: 빅 KPI + 리스트 + 도넛 3단 → **Module 8 Owner Report 즉시 적용**
- **page-035 스케줄**: 캘린더+시간 슬롯+예약 카드 3단 뷰 → 스케줄 모듈 멀티 뷰
- **page-037 상품 조회/결제**: 썸네일+가격+chip 카드 + 옵션 전/후 좌우 비교
- **page-038 출석/키오스크**: 헬스장 사진 + UI 합성, QR/전화/안면인식 비교
- **page-041 환불**: ▲ 빨강 + 섹션별 컬러 분리(오렌지/핑크/라일락)
- **page-043 설정**: 결제내역=노랑 / 안면=민트 / 보호자=보라 / 알림=토글 — 기능별 Pastel 섹션 분리
- **page-060 회원 정보 개편**: 보유 상품 + 센터 이용 정보 카드 분리
- **page-085 그룹 수업 관리**: 좌석 배치도 업로드, 그룹 수업 복사, 자동 알림
- **page-088 출석 풀 가이드**: 4가지 출석 방식 비교 매뉴얼
- **page-089 자동 출입 마케팅**: 디바이스 사진 + 가격표 + 풀폭 CTA → 랜딩 정석
- **page-090 안면인식 등록**: 번호 매긴 단계별 안내 + 외부 서비스(토스) 연동

## OUHVE에 흡수할 UI 패턴 Top 12

1. **챕터 표지 컬러 카드(Slate 변주)** — 모듈 인덱스/도움말
2. **빅 KPI + 리스트 + 도넛 3단 통계 카드** — Module 8 핵심
3. **두 화면 좌우 비교(Before/After) 가이드 카드**
4. **풀폭 하단 고정 Primary CTA (모바일)**
5. **상단 일러스트 도입 카드** — Pastel 배경
6. **기능별 Pastel 섹션 분리** — 설정/정책 그루핑
7. **카테고리 chip (검정+흰)**
8. **상품 카드 (썸네일+가격+chip)**
9. **컨텍스트 사진 합성** — 디바이스+UI
10. **상태 dot + 텍스트** — Teal 도형 규칙과 일치
11. **세로 단계 카드 (번호+캡쳐)** — 복잡 워크플로우 매뉴얼
12. **단조 톤 차트 색** — Persimmon + Slate-500 + Slate-300

## OUHVE 충돌 (적용 X)
1. 챕터별 자유 풀컬러 (빨강/파랑/보라/녹색) → **Slate 톤 변주** 또는 Persimmon 1색만
2. Teal/Forest Green 카테고리 풀배경 → **Teal은 도형/점/선만, 글자/풀배경 금지**
3. Indigo/Purple/Pink chip → Slate chip 대체
4. 이모지 도입부 → Lucide 아이콘
5. Orange 글로우 과사용 → `.glow-primary` 페이지당 1개 제한 유지

## 요약
- AssistFit = 운영자(헬스장 사장) 친화적 디자인: 위험 액션 컬러 분리, 단계별 캡쳐 매뉴얼, 모바일 풀폭 CTA, KPI 중심 통계.
- 컬러 다양성은 OUHVE 규칙과 충돌하지만 **패턴(레이아웃/카드/일러스트 도입/단계별 매뉴얼/CTA)** 은 흡수 가능.
- 운영자 친화 통계+도움말의 완성도가 OUHVE 차별화 무기가 될 수 있음.
