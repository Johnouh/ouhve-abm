경로
· 상품 → 상품 추가 → 회원권/그룹 수업 선택 시 
그룹 수업 예약 취소 가능 횟수 / 시간을 설정할 수 있어요.
•
그룹 수업을 더 원활하고 체계적으로 운영할 수 있도록 기능을 추가했어요.
•
취소 가능 횟수 설정을 통해 유효 기간 내 또는 월 별로 횟수를 회원에게 부여할 수 있고, 회원은 횟수 내에서만 수업 예약 취소가 가능해요.
•
취소 가능 시간 설정을 통해 수업 취소가 가능한 시간을 설정하면 회원은 설정한 시간 전까지만 예약 취소가 가능해요.
