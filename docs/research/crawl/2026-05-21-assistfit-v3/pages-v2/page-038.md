출석
어시스트핏 회원앱을 이용해 수업 출석을 할 수 있어요.
키오스크 사용
출석 방법
QR 코드 출석
홈 → (카테고리) 출석 버튼을 클릭해 이용할 수 있어요.
출석 버튼을 누르면 노출되는 QR 코드를 키오스크의 카메라에 촬영해 주세요.
전화번호 출석
출석 방법 중, ‘전화번호’를 클릭한 후 회원님의 전화번호를 입력해 주세요.
안면인식 출석
출석 방법 중, ‘안면인식’을 클릭한 후 키오스크 카메라에 얼굴을 촬영해 주세요.
출석을 할 수 없나요?
사용 예정인 상품일 경우
서비스 시작일에 제한을 둔 경우, 상품을 이용할 수 없어 출석도 진행할 수 없어요.
아래 보이는 화면이 노출되면서 출석을 할 수 없다면 시설에 직접 문의해 주세요.
결제 취소 / 환불을 한 경우
시설에 결제 취소 또는 환불을 요청한 경우, 해당 상품을 이용해 출석을 할 수 없어요.
 결제 취소 / 환불
이용 중지일 경우
상품이 이용 중지 상태일 경우, 해당 상품을 이용해 출석을 할 수 없어요.
