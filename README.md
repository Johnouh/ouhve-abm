# OUHVE ABM 체육관 관리 시스템

## 빠른 시작

1. **의존성 설치 및 실행**:
```bash
./run-local.sh
```

2. **수동 실행**:
```bash
npm install
npm run db:push
npm run dev
```

3. **브라우저에서 접속**:
- http://localhost:5000

## 주요 기능
- 회원 관리
- 직원 관리
- 상품 관리
- 사물함 관리
- 출석 관리
- 상담 관리
- 통계 및 리포트

## 기술 스택
- Frontend: React 18 + TypeScript + Tailwind CSS
- Backend: Express.js + TypeScript
- Database: PostgreSQL (Neon 클라우드)
- ORM: Drizzle ORM
- Authentication: Passport.js

자세한 설정 방법은 `LOCAL_SETUP_GUIDE.md`를 참고하세요.
